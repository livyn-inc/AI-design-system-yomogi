# Reference Mixing

Reference Mixingは、参考サイトや資料を見た目のコピー元ではなく、考え方・構造・文脈を抽出する材料として扱うための手順。

プロの参照は模倣ではない。複数の参照から、写真、情報設計、余白、タイポグラフィ、UI文法、文化的文脈などを分解し、今回のコンセプトに合わせて再構成する。

## Core Rules

- 1つの参照に寄せすぎない。
- 参照ごとに「何を借りるか」を明記する。
- 参照ごとに「何を真似しないか」も明記する。
- 見た目、レイアウト、ブランド固有表現、ロゴ、コピーの丸写しを避ける。
- 最終コンセプトに合うように再構成する。
- 未確認URLを断定的に出さない。

## URL Policy

標準ではURLではなく、検索キーワードと見る観点を出す。

URLを使ってよい場合:

- ユーザーがURLを提示した。
- AgentがWebで確認できた。
- 実在性と、どの観点で参考にするかを説明できる。

URLを使わない場合:

- 記憶だけでそれっぽいURLを出す。
- 実在性を確認できない。
- 今回の方向性に合う理由を説明できない。

## Search Keywords Format

```text
参考検索キーワード:
- [検索キーワード1]
- [検索キーワード2]
- [検索キーワード3]

見る観点:
- 写真の温度感
- 情報設計
- 余白とグリッド
- タイポグラフィ
- UI部品の明快さ

抽出したい考え方:
- [今回のコンセプトに使う考え方]

真似しない点:
- レイアウトの丸写し
- ブランド固有の色やロゴ
- コピーや固有表現
```

## Reference Mix Format

```markdown
## Reference Mix

### 写真 / ビジュアル素材
- 参照文脈: [媒体、文化、時代、ジャンル]
- 借りる考え方: [温度感、距離感、被写体の扱いなど]
- 真似しない点: [固有の写真表現、ブランド感など]

### 情報設計
- 参照文脈: [EC、編集誌、管理画面、資料、店舗体験など]
- 借りる考え方: [情報の並べ方、優先順位、比較のしやすさなど]
- 真似しない点: [そのままのレイアウトや構成]

### タイポグラフィ
- 参照文脈: [雑誌、アーカイブ、プロダクトUI、広告など]
- 借りる考え方: [緊張感、読みやすさ、ラベル感、見出しの強さなど]
- 真似しない点: [特定ブランドの書体選びやロゴ感]

### UI文法
- 参照文脈: [プロダクトUI、EC、カタログ、ダッシュボードなど]
- 借りる考え方: [カード、タグ、一覧、比較、状態表示など]
- 真似しない点: [既存UIの見た目のコピー]

### 文化的文脈
- 参照文脈: [音楽、ファッション、道具、地域、時代など]
- 借りる考え方: [背景思想、態度、空気感]
- 真似しない点: [記号だけの浅い引用]
```

## User-Facing Phrasing

ユーザーには、必要に応じて短く説明する。

```text
参考をそのまま真似るのではなく、複数の文脈から考え方を分解して混ぜます。
今回は、写真の温度感、情報設計、タイポグラフィ、UIの明快さを別々に見ます。
```

ユーザーがURLを出した場合:

```text
このURLは見た目をコピーするのではなく、どの考え方を参考にするかに分解して使います。
```

## Example: Vintage Fashion EC

```text
写真の温度感:
若い男性が日常のファッションとして着ているスナップ文脈を参考にする。
商品を資料ではなく「今日着たい服」として見せる。

情報設計:
現代ECの商品一覧と商品詳細の見やすさを参考にする。
Front/Back、年代、素材、買い付けメモを迷わず見られる構造にする。

タイポグラフィ:
アーカイブや商品タグのラベル感を参考にする。
ただし古い紙資料や博物館感に寄せすぎない。

UI文法:
商品カード、タグ、比較、保存、フィルタの明快さを参考にする。
雑多なフリマ感やハイブランドECの距離感は避ける。
```
