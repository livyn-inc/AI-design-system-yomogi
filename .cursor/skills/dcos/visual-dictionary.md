# Visual Dictionary

感情語を視覚語へ変換するためのAgent内部用の基礎辞書。これは答えではなく、発想の出発点。対象ユーザー、サービスカテゴリ、価格帯、信頼性、避けたい既視感で必ず補正する。

ユーザーには、この辞書をそのまま説明しない。ユーザーの曖昧な言葉を受け取り、自然なデザイン方向性として返す。

## Emotion To Visual Language

| 感情語 | 視覚語の候補 | 注意点 |
|---|---|---|
| 楽しそう | ポップカラー、カード、チップ、ステッカー、丸み、リズム | BtoBでは幼さを避け、操作感や道具感で出す |
| 信頼できる | 余白、整列、低彩度、明確な階層、読みやすい文字 | 無難になりすぎないよう、固有の図形文法を作る |
| 未来感 | グリッド、光、抽象図形、奥行き、グラデーション | AIっぽい脳、粒子、青紫だけに寄せない |
| 親しみ | 暖色、丸み、柔らかい面、低コントラスト、手触り | 甘くなりすぎる場合はタイポとレイアウトで締める |
| 道具感 | パネル、入力UI、太線、明快なボタン、ステップ構造 | 業務システム感だけにならないよう色や図形で個性を足す |
| 高揚感 | 強いアクセント、斜め構図、コントラスト、光、速度感 | 長時間使うUIでは、常時強調ではなく要所に限定する |
| 知的 | グリッド、細い線、余白、図解、落ち着いた配色 | 冷たく見える場合は人間味のある要素を足す |
| 先進的 | 非対称レイアウト、抽象形状、透明感、レイヤー | 操作対象が分かりにくくならないようUI部品は明快にする |
| やさしい | 柔らかい角、淡い色、広めの余白、自然なアイコン | 情報密度が低くなりすぎないよう構造を保つ |
| プロっぽい | 明確な階層、落ち着いた色、端正なタイポ、余白 | 硬すぎる場合はアクセントやマイクロコピーで緩める |

## Context Adjustment

同じ感情語でも文脈で変換を変える。

```text
BtoB AIワークフローの「楽しそう」
→ ステッカー、色面、カード、チップで楽しくする。ただしキャラクターや幼さは避ける。

教育アプリの「楽しそう」
→ イラスト、丸み、達成バッジ、キャラクターも候補に入る。

金融SaaSの「楽しそう」
→ 色で遊びすぎず、操作の軽さ、進捗感、マイクロインタラクションで出す。
```

## Counter-Cliche Translation

ユーザーが避けたい既視感を話したら、代替表現に変換する。

```text
無難なSaaSにしたくない
→ 白背景 + 青アクセント + 抽象ダッシュボードを避ける
→ 代替候補:
  - 色面を強める
  - タイポを強くする
  - 図形文法を作る
  - 余白より密度で個性を出す
  - レトロ/未来/道具感の参照を入れる
```

## User-Facing Rewrite

内部変換をそのまま出さず、ユーザーにはこう返す。

```text
「会計ソフトっぽくしたくない」という条件から見ると、
白背景に青いボタンの管理画面より、
制作進行やアトリエの道具に近い見せ方が合いそうです。
```
