## 🎯 強調判定フロー

### 基本評価式
**デザイン品質 = ID × CX × AE × DP**
- **ID** (情報密度): 0-1.0 - 占有面積 ÷ 表示領域
- **CX** (コンテキスト): 0-1.0 - プロダクト・ページ・設計意図の適合度
- **AE** (美的表現): 0-1.0 - ブランド・色彩・統一性・主役脇役バランス
- **DP** (発見可能性): 0-1.0 - UI要素の発見しやすさ

### 強調手段選択フロー
```
Step1: 要素分類
├─ アクション要素 → ボタンヒエラルキー適用
├─ 状態表示 → Tag色システム適用
└─ 情報要素 → 強調エスカレーション戦略適用

Step2: 強調度計算（詳細は評価システム参照）
総強調度 = CP × SP × MP × AP × KP × FWP

Step3: 全体調和チェック
├─ 1画面1つの最大強調（10pt超）
├─ ヒエラルキー逆転防止
└─ ページ目的との整合性確認
```

## 🎭 強調アプローチ選択チェックリスト

### 基本戦略選択
- [ ] **絶対強調**: 対象要素を直接変更（サイズ↑・色強化・背景追加）
  - 適用: 単独強調・インパクト重視・低密度ページ
  - 注意: 多用でバランス破綻リスク
- [ ] **相対強調**: 周辺要素を抑制（opacity↓・サイズ↓・色薄化）
  - 適用: 調和重視・高密度ページ・複数要素強調
  - 注意: 効果が控えめ
- [ ] **ハイブリッド**: 軽微絶対 + 相対組み合わせ
  - 適用: バランス重視・汎用性
  - 注意: 微調整必要

### AI提案パターン確認
強調要求時は以下3案検討：
- [ ] **案A**: 絶対強調（確実・インパクト大）
- [ ] **案B**: 相対強調（上品・調和保持）
- [ ] **案C**: ハイブリッド（推奨・バランス型）

### 選択判断要因チェック
- [ ] **情報密度**: 高密度→相対強調、低密度→絶対強調
- [ ] **ブランドトーン**: 上品→相対、ダイナミック→絶対
- [ ] **ユーザー層**: 慎重→相対、アクティブ→絶対
- [ ] **目的**: 認知→相対、行動→絶対
- [ ] **要素数**: 複数→相対、単独→絶対

## 📊 強調度計算システム

### 基本計算式
**総強調度 = CP × SP × MP × AP × KP × FWP**

### ポイント体系（基準値1.0）
- **CP** (コントラスト): 1.0-3.0
- **SP** (サイズ): 1.0-4.8+
- **MP** (余白): 1.0-3.0
- **AP** (領域): 1.0-2.8
- **KP** (動き): 1.0-4.0
- **FWP** (フォントウェイト): 1.0-1.5

### 強調度レベル基準
- [ ] **レベル1** (1.0-2.5pt): 軽微強調
- [ ] **レベル2** (2.6-5.0pt): 中度強調
- [ ] **レベル3** (5.1-10.0pt): 高度強調
- [ ] **レベル4** (10.1pt+): 最大強調（1画面1つまで）

> 📊 **詳細計算・評価**: [評価システム詳細](./emphasis-evaluation-detailed.md)参照

## 💡 活用のポイント

### 効果的な運用
1. **段階的適用**: 軽微→中度→高度の順で検討
2. **全体調和**: ページ全体の強調度バランス確認
3. **目的重視**: ビジネス価値と強調度の一致
4. **測定改善**: 実装後の効果測定・調整

### よくある失敗パターン回避
- ❌ 過度な強調（全体が騒がしい）
- ❌ 一貫性欠如（同じ要素で異なる強調）
- ❌ 目的不明確（なんとなく目立たせる）
- ❌ アクセシビリティ軽視（コントラスト不足）

## 🔧 強調システム実用化改善

### 追加評価項目
- [ ] **レスポンシブ影響度**: モバイル/デスクトップでの効果差は適切か
- [ ] **実装複雑度**: CSS複雑さ（1-5段階で評価）
- [ ] **保守性**: 将来変更時の影響範囲は限定的か
- [ ] **パフォーマンス**: レンダリング負荷への影響は軽微か

### 総合品質レベルガイド
- **0.5以上**: 優秀（推奨レベル）
- **0.4-0.5**: 良好（実用的で問題なし）
- **0.3-0.4**: 標準（改善余地あり）
- **0.2-0.3**: 課題（要改善）
- **0.2未満**: 問題（大幅修正必要）

### 段階的改善ロードマップテンプレート
```
現在: ID×CX×AE×DP = 0.xxx
目標: 0.5以上（優秀レベル）

改善施策:
1. [要素] 現在値→目標値 （手段）
2. [要素] 現在値→目標値 （手段）
3. [要素] 現在値→目標値 （手段）

期待効果: +xx%向上
```

### 実用性検証済み事例

#### ✅ modern-chat UI改善実績
**改善前**: 0.389（標準レベル）
**改善後**: 0.445（良好レベル）
**向上率**: +14.4%

**具体的施策**:
- アイコンサイズ: 32px→48px（SP 1.0→1.5）
- メッセージ余白: 20px→32px（MP 1.0→1.6）  
- 角丸改善: radius-lg→2xl+直角（AE 0.8→0.9）
- 視覚的関係性: 接触感強化（CX 0.9→0.95）

**学習点**:
- トークン存在確認の重要性（44px→48px代替）
- 段階的提案の有効性（A/B/C選択肢）
- 視覚的品質の定量化可能性
